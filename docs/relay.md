# 中继（ProxyIP）

## 为什么需要中继

Cloudflare Worker 不能连 Cloudflare 自己的 IP（平台限制，出站会被拒）。所以目标是
Cloudflare 承载的站点时，必须借一个第三方中继出站：

```
浏览器 ──▶ netmaster ──▶ CF 边缘(worker) ──▶ 中继 ──▶ 目标站
```

**这一跳的出口 IP 决定了 Cloudflare 系站点给你 200 还是 403。** 站点看到的是中继，不是你。

## 中继列表：动态获取 + 内置兜底

列表内容从社区源动态获取（`forward.js` 的 `RELAY_SOURCE`，ipdb 的反代优选，
isolate 内缓存 1 小时），获取失败并上 `FALLBACK_RELAYS`（9 个 `*.CMLiussss.net`
公共中继）兜底。

硬编的是"从哪拿列表"而不是列表本身：公共中继说挂就挂、说被拉黑就被拉黑，
静态列表必然过期。探测 + 亲和才是自愈机制，列表只是候选集。

裸 IP 候选会被包成 `sslip.io` 主机名（`1.2.3.4` → `1.2.3.4.sslip.io`），因为
探测走 `resolveOverride`，要求主机名。非 443 端口的候选直接丢弃 —— 中继的
语义就是反代 Cloudflare 的 443。

> 公共中继是别人维护的共享资源，**随时可能挂、也随时可能被目标站拉黑**。它们不是可靠基础设施。

## 中继选择的两个阶段

### 1. 选（`pickRelayFor`）

只在**该域名尚无绑定**时触发，最多探测 4 个候选，总预算 3s。

探测方式：`fetch("https://<目标>/", { cf: { resolveOverride: "<中继>" } })`。
URL 提供目标，所以 SNI 和 Host 都是目标的，TCP 连到中继——和真实转发走的是同一条路。

**判定规则**：拿到 **403 就淘汰**这个中继——中继成功到达了目标，是目标拒绝了这个出口 IP，
这正是唯一值得绕开的情况。其余 2xx/3xx/4xx/5xx 都算通路可用（4xx/5xx 可能是站点自己的问题）。

### 2. 记（D1 持久化）

亲和 `host → 中继` 会写入 D1（表 `relay_binding`，主键 `host`，带 `updated_at`），新 isolate 先读它再决定是否
探测。

**为什么必须持久化**：亲和若只活在 isolate 内存里，而 isolate 是常被回收的——
每个新 isolate 各自重选一个中继，好赖全凭运气，表现出来就是同一个站点时通时断。
持久化让新 isolate 从已学到的结果开始，而不是每次重掷骰子。

读写都是 best-effort：D1 缺失或出错只是退化成探测，不会让请求失败。

## 诊断

没有诊断端点（Worker 不暴露任何 HTTP 端点）。要回答"某个站是不是被中继出口 IP
拉黑"，只有两条路：

1. **`DEBUG=1` + `wrangler tail`**：日志里有每次中继选择的探测结果
   （`<host>: relay <relay> answers <status>` / `no relay answered cleanly`）。
2. **临时加回一个诊断端点**：`/relaycheck` 的实现在 git 历史里，需要时把它
   临时加回 `index.js`，测完删掉。日常留着它违背"零端点"的设计，但诊断价值
   是真实的 —— 它是唯一能从 Worker 视角逐个问中继"这个域名经你会返回什么"的手段。

## 自建中继

公共中继被目标站拉黑是常态（共享 IP、共享用途）。要稳定访问这类站点，只能用自己控制的
出口：

1. 找一台境外 VPS
2. 部署一个支持按 SNI 反代 Cloudflare HTTPS 的中继（cmliu 的 edgeProxy / nginx 均可）
3. 把主机名加进 `forward.js` 的 `FALLBACK_RELAYS`（自用不改源码的话，等
   `RELAY_SOURCE` 支持自定义来源再做）

保留几个公共中继做兜底。自建中继一旦被拉黑，换 IP 即可，不再受第三方连带影响。

## 排障

| 现象 | 查什么 |
|---|---|
| 某个 CF 站稳定 403 | `DEBUG=1` 看 tail 日志里该域名各中继的探测状态；全 403 → 换中继或自建 |
| 间歇 000 / 连接重置 | 日志里 status=0 的中继是连不上的；D1 学到能用的那个之后就稳定 |
| 首次请求很慢（几秒） | 正常：那一轮在探测中继（最多 4 个候选，预算 3s），命中 D1 后就不会了 |
