# 语法: <action> <kind> <value>
#   action = direct | proxy          （某条规则的动作）
#   kind   = domain | suffix | cidr  （domain 已含精确匹配；suffix 只匹配子域；cidr 匹配 IP）
# 未命中任何规则的走文件末尾的 `default auto`。

# 匹配类型只有上面三种：每种都要有人真的用才留。

# ---------- 局域网/本机直连 ----------
direct cidr 127.0.0.0/8
direct cidr 10.0.0.0/8
direct cidr 172.16.0.0/12
direct cidr 192.168.0.0/16
direct cidr 169.254.0.0/16
direct domain localhost
# IPv6 侧。localhost 常优先解析成 ::1，漏了它本机服务会被送去代理，
# 再由边缘去连 ::1 —— 必然失败。
direct cidr ::1/128
direct cidr fc00::/7
direct cidr fe80::/10

# ---------- 兜底 ----------
# 未明确列出的主机交给出口层自动判断（route.Auto）：解析域名后落在 CN 网段就直连，
# 否则走代理；两条路互相回退，并按域名记住选择。
#
# 注意这里不能改成按后缀穷举送代理：域名列表无法穷举，那会把大量国内 IP、
# 没被墙的站点绕到海外再绕回来。
default auto
