# .collab — 两个会话之间的协作面

主会话（`main`）与协助者会话（assist）共用本目录。**这是双方唯一双向可碰的地方**：
主会话拿不到对方的 `sess_*` id，本机也没有可读的会话存储，所以「起一个消息服务」
解决不了首次触达。仓库里的文件是唯一一开始就能被对方看到的通道。

## 怎么用

| 路径 | 谁写 | 内容 |
|---|---|---|
| `README.md` | 双方，但很少改 | **契约**：规约、已验证的平台事实、已达成的决策 |
| `lanes/main.md` | 主会话 | 我这一轮在做什么、已完成什么、留给对方什么 |
| `lanes/assist.md` | 协助者 | 同上，另一条车道 |
| `inbox/<lane>/` | 对方的 | 留言：`YYYYMMDD-HHMM-主题.md`，按文件名排序读 |
| `history.md` | 只读 | 全部历史记录（从 co-work.md 搬过来，已 975 行） |

**车道各写各的。** 上一份板子的失败模式很具体：两个人都往同一个文件末尾追加，
后写的覆盖先写的，而且它在 `.gitignore` 里——清掉就没了（`.assist/` 2026-10-03 被清空过一次）。

## 启动时读什么

1. `README.md`（契约，每次都读，很短）
2. `lanes/<自己的>.md`（自己这条）
3. `lanes/<对方的>.md`（对方做到哪了）
4. `inbox/<自己的>/` 里有没有新留言（文件名比当前时间新的）

## 规约（来自 history.md 里血亏换来的几条）

1. **提交前验证这个提交自己能不能编过**：
   `git worktree add --detach /tmp/x HEAD && cd /tmp/x && bash scripts/test-all.sh`。
   只看工作区能编是不够的——工作区里往往还躺着别人的未提交实现，把洞盖住了。
2. **只 `git add` 自己的文件**，不用 `-A`。但这条防不住「我依赖的符号还在别人手里」，
   所以要配第 1 条。
3. **每个修复都要有一条"去掉接线就会红"的测试**，并且真去去掉一次试试。
   本项目已经有两条测试过不了这一关（`TestMuxTargetFromConfig` 只能抓住一半；
   `TestIdleTrimActuallyShrinksThePool` 抓不住两处修复中的任一处单独效果）——写进去，别糊过去。
4. **没量过就别写"实测"**。本项目最贵的一次错误是把「11 个候选里 8 个被拒」当成
   「边缘在拒绝」，而那 8 个其实是明文 SNI 握手刚完就被 GFW RST。
5. **新写的并发/时序测试要 `-count≥6` 跑**。单次绿灯在这类代码里没有信息量。
6. **文档承诺了代码没做的事 = bug**（A8 抓到一次「空闲回收已实施」；
   这一轮又抓到「空闲期收缩到一条」和「ECH 默认隐 SNI」两处）。
7. **失败要显眼**。ECH 静默退回明文 SNI 藏了整整一个版本，用户以为自己被保护着。

## 已验证的平台事实（别重复踩）

- `*.workers.dev` 在大陆被 SNI 阻断；不发布 ECH。部署必须绑自定义域名（`deploy.yml` 有门）。
- 免费版 DO duration **13,000 GB-s/日**（≈28.2 DO·小时/天），超额**硬失败**；能休眠的空闲 DO 不计。
- 免费版单 DO 存储 **1 GB**（10 GB 是付费版）。
- 20:1 WS 折算**只作用于 billing**。50 子请求/invocation；DO 间 fetch 与 connect 同池。
- 裸 TCP 探测测不出「TCP 通但 TLS 被 RST」。入口源里约有三成候选**真的**建不了隧道
  （Cloudflare 403 / error 1034），用串行重探复核过 20 条，0 条冤枉。
- 边缘 IP 在 WS 升级阶段回 403/1034 是真实存在的一类坏节点，**不是探测并发造成的**
  （并发 3/6/12 三档都做过，冤枉率都是 0）。
